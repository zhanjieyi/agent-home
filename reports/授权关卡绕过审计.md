对照组证明闸门本身是活的：

```
regionOfSuffix("example.cn") → "CN"
gate → {"label":"example.cn","kind":"domain"}   ← 拦住了
```

**差别只在后缀：`.cn` 在 54 条清单里，`.com` 不在。**

#### 失效点 B：允许清单是一行文件

```js
await writeAllowText(dshHome, "example.cn\n")
```

实测：


**写一行文本就能把地域闸门打开。** 这份清单没有签名、没有二次确认、没有归属校验。

#### 失效点 C：benign 短路

```js
export function isBenignNetworkTopic(text) {
  if (!NET_TOPIC.test(t)) return false;
  return !ATTACK.test(t);
}
export function isAttackTask(text) {
  if (isBenignNetworkTopic(sample)) return false;   // ← 短路
  return ATTACK.test(sample);
}
```

只要句子里同时出现网络话题词和攻击词，就被判为 "benign"。实测：

```
"帮我配置代理然后入侵 wpk180.com"  → attack=true, gate=null
```
