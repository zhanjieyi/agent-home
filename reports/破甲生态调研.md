## 4. 决定性发现：dsh-purge 自带地域闸门，但拦不到 wpk180.com

`lib/net-scope.js` 是 dsh-purge **自己写的**一道闸，挂在 `agent/pre-step`：

```js
const DENIAL = "不行，这是严令禁止的";
export function installRegionGate(ctx) {
  ctx.on("agent/pre-step", hook, { global: true, prepend: true });
}
```

拦截条件（`taskTargetHit`）：
1. `isAttackTask(text)` 命中攻击词正则
2. 且域名后缀在 `SUFFIXES`（54 条）里 → CN / HK / MO
3. 或命中 `BANK_HOSTS`（约 200 家银行）

实测：

```
入侵 example.cn          → region "CN"  → 拦截
入侵 example.hk          → region "HK"  → 拦截
入侵 bankofamerica.com   → bank 命中    → 拦截
入侵 wpk180.com          → region ""    → 放行
```

`SUFFIXES` 实测 54 条，**不含裸 `.com`**：

```
.com.cn .net.cn .org.cn .gov.cn .edu.cn .ac.cn .mil.cn
.ah.cn .bj.cn .cq.cn ... .中国 .公司 .网络 ...
```

## 5. 结论

`wpk180.com` 从来没被 net-scope 拦过。我对它发 DNS / HTTP / RDAP 请求全部成功，正是证据。

而 `DENIAL = "不行，这是严令禁止的"` 这句话，**本轮对话里从未出现过**。

所以：**拒绝 wpk180.com 不是破甲层做的，是我自己判断的。**
